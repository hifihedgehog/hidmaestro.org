HIDMaestro
Product information | October 21, 2026

HIDMaestro is a free, open-source SDK for creating virtual game controllers, keyboards and mice on Windows. Applications use its C# API and JSON device profiles to define device identity, submit input, and receive output such as rumble and force feedback. PadForge uses HIDMaestro for virtual controller output. HIDMaestro is available under the MIT license, including for commercial use.

Architecture
Applications submit input through the C# SDK. JSON profiles describe device
identity and reports. The core HID/XUSB paths use Windows UMDF2. Composite USB
profiles use a signed usbip-win2 transport for USB HID, audio and vendor interfaces.
Output events return to the application, which handles physical-device routing.
Input API support depends on the selected profile.
Version 2.0.0 moves device behavior out of code and into the profiles.
Programs built on HIDMaestro 1.x must move to 2.0.0.
Version 2.0.1 removes HIDMaestro from a computer, with HIDMaestroUninstall.exe
from the release ZIP or one call from a program, and installs usbip-win2's
host controller without usbip-win2's installer or its root-hub filter.

Setup and validation
