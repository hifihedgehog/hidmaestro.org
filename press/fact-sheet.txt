HIDMaestro
Product information | October 25, 2026

HIDMaestro is a free, open-source SDK for creating virtual game controllers, keyboards and mice on Windows. Applications use its C# API and JSON device profiles to define device identity, submit input, and receive output such as rumble and force feedback. PadForge uses HIDMaestro for virtual controller output. HIDMaestro is available under the MIT license, including for commercial use.

Architecture
Applications submit input through the C# SDK. JSON profiles describe device
identity and reports. The core HID/XUSB paths use Windows UMDF2. Composite USB
profiles use a signed usbip-win2 transport for USB HID, audio and vendor interfaces.
Output events return to the application, which handles physical-device routing.
Input API support depends on the selected profile.
Version 2.0.0 moves device behavior out of code and into the profiles.
Programs built on HIDMaestro 1.x must move to 2.0.0.
Version 2.0.1 removes HIDMaestro from a computer, with HIDMaestroUninstall.exe
from the release ZIP or one call from a program, and installs usbip-win2's
host controller without usbip-win2's installer or its root-hub filter.
Version 2.0.2 gives the Steam Deck and Steam Controller personas the motion,
report timing, unit serials, pad pressure and trigger bits that SDL and Steam
read from the real controllers.
Version 2.0.3 makes a removal that includes usbip-win2 take usbip-win2's
root-hub filter too, which an SDK through 2.0.0 installed.
Version 2.1.0 keeps the Xbox 360 profiles' HID devices alive across a system
sleep, and cuts the work the SDK and the USB/IP transport do for each frame.

Setup and validation
Device creation and driver installation require administrator rights.
For 2.1.0, the 100-scenario regression battery passed on the development
laptop, a 16-core Lenovo Legion Pro 7 on Windows 11. On a 4-core Celeron
J4125 Windows 10 mini PC, 96 scenarios passed and 4 skipped, leaving out the
checks that need a Steam client, a desktop session or Windows Sandbox.
ARM64 binaries were built and signed, but the regression battery has not
been run on ARM64 hardware.

Performance
Each release's notes compare it with the release before it, both builds
measured in one session on the development laptop. Chained from those
comparisons, 2.0.2 takes 76% of 1.12.0's time from process start to the first
DualShock 4 controller, 43% of its time to create an Xbox 360 controller, and
77% of its time from SubmitState to a game's ReadFile on a DualShock 4. Every
tracked path, slower steps included: https://hidmaestro.org/performance.html

Adoption
PadForge is built on HIDMaestro end to end. Other public projects that use,
ship or build on it include foundation-sunshine, Vibepollo, Sunshine Control
Panel, Kitsune Input, HandHeld Legend's HHL Gamepad WLAN and
JoystickGremlinEx, 45 projects in all: https://hidmaestro.org/specs.html#adopters
