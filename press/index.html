The project

About HIDMaestro

HIDMaestro is a free, open-source SDK for creating virtual game controllers, keyboards, mice, touchscreens, touchpads and pens on Windows. Applications use its C# API and JSON device profiles to define device identity, submit input, and receive output such as rumble and force feedback. PadForge uses HIDMaestro for virtual controller output. HIDMaestro is available under the MIT license, including for commercial use.

Download fact sheet

Built on the UMDF2 approach pioneered by Nefarius in DsHidMini. The DualShock 3 profile uses DsHidMini's report descriptor. Composite USB profiles use usbip-win2 by Vadym Hrynchyshyn. Third-party notices.
